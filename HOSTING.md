# Recommended Hosting

Squirrels is designed to work on any standards-compliant WordPress hosting provider that meets the current WordPress and WooCommerce requirements.

Our development, quality assurance, and demonstration environments are hosted on **WPMU DEV Managed Hosting** using the latest supported PHP version. This provides a consistent platform for testing, performance benchmarking, and validating new releases.

While Squirrels is compatible with any standards-compliant WordPress host, we recommend using a hosting provider that offers:

* The latest supported PHP version
* Automatic SSL certificates
* Daily backups
* Staging environments
* SSH and WP-CLI access (recommended for developers)
* Server-side caching and modern performance features
* Reliable uptime and security monitoring

Using a modern managed WordPress host helps ensure the best experience for both site owners and developers, particularly when working with WooCommerce stores.
