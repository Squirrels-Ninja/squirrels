## CUSTOMIZER SECTION

**Section headline**
Your brand. Your settings. No code.

**Section subheadline**
The Squirrels Customizer gives you real-time control over the settings that matter most, using WordPress's native interface.

**Left column — what you can change**
- Primary colour (affects navigation, links, buttons, product prices)
- Accent colour (affects sale badges and CTA highlights)
- Body font size (12–24px range, live preview)
- Sidebar position (left, right, or no sidebar — per global setting)
- Footer copyright text

**Right column — how it works**
Every setting saves as a WordPress theme mod — not a plugin option, not a database row in a third-party table. Deactivate the theme and your settings travel with it. No lock-in.

All colour changes output via CSS custom properties, which means child theme authors can reference `--squirrels-primary` directly in their own stylesheets.

## CHILD THEME SECTION

**Section headline**
Make it yours without losing updates.

**Body copy**
Squirrels ships with a ready-to-use child theme. Install it alongside the parent, activate it, and every customisation you make — custom CSS, template overrides, additional functions — is protected when the parent theme updates.

The child theme enqueues the parent stylesheet correctly with the right dependency chain. No copy-paste required.

**Install note**
Download `squirrels-child-1.0.0.zip` separately. Upload via Appearance → Themes → Add New → Upload Theme.

## FAQ SECTION

**Section headline**
Questions

---

**Q: Does this theme require a page builder?**
No. Squirrels works with the native WordPress block editor and requires no page builder to match the demo. Starter site import creates real pages with real block content.

---

**Q: Do I need WooCommerce to use this theme?**
No. Squirrels works as a standard WordPress blog/business theme without WooCommerce. WooCommerce support activates automatically when the plugin is present.

---

**Q: Will my store break when I update the theme?**
Updates to Squirrels follow semantic versioning. Patch versions (1.0.x) are safe to apply without review. Minor versions (1.x.0) include new features and will note any template changes in the changelog. If you use the child theme, your template overrides are never touched by parent theme updates.

---

**Q: Is this compatible with my WordPress version?**
Squirrels requires WordPress 6.0 or later and PHP 7.4 or later. It is tested up to the current WordPress release.

---

**Q: Where do I get support?**
Free theme support is available via the GitHub issue tracker. Response times vary. Pro support includes a private support channel with guaranteed response times. See the Support Policy for full details.

---

**Q: Can I use this for a client project?**
Yes. Squirrels is licensed under GPL v2 or later. You may use it on unlimited sites, including client sites.

---

**Q: Where is the Pro version?**
Squirrels Pro is in development. Sign up for the launch notification list to be notified when it is available.
