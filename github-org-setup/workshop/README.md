# Workshop — Pro Companion Plugin for Squirrels

> **Status:** Planned · Not yet released

Workshop is the Pro companion plugin for the [Squirrels](https://github.com/Squirrels-Ninja/squirrels) WordPress theme. It extends the free theme with advanced features aimed at professional WooCommerce stores.

## Planned features

- **Advanced Blocks** — Custom Gutenberg blocks for hero sections, product showcases, testimonials, and feature grids
- **Enhanced WooCommerce** — Ajax filters, product quick-view, wishlist, comparison, and advanced checkout fields
- **Email Designer** — Branded WooCommerce transactional emails with the Squirrels visual system
- **SEO & Schema** — JSON-LD structured data for products, organization, and breadcrumbs
- **Performance Dashboard** — One-click Scamper optimization settings
- **Analytics Integration** — GA4 and Meta Pixel event tracking for WooCommerce

## Licensing

Workshop is a commercial plugin. Free theme users can upgrade at [squirrels.ninja/workshop](https://squirrels.ninja/workshop).

## Requirements

- WordPress 6.3+
- WooCommerce 8.0+
- Squirrels theme 1.0.0+
- PHP 7.4+
